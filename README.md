# GPT-SoVITS 语音朗读 + 听写（Foundry VTT 模块）

打字即朗读：把聊天框里的台词用 **GPT-SoVITS 本地语音克隆**读出来，并按台词情绪**自动切换语气与立绘**。
内置浏览器系统语音、麦克风听写（语音转文字）。

> 致谢：借鉴了不二咲爱笑大佬制作的 **Shinsekai**。制作人：跑团恶魔。交流群：775375241。
> 当前版本：**1.6.118**（`module.json` 与代码内 `MOD_VERSION` 同步）

---

## 一、它到底怎么工作（先看这段，少走弯路）

一句话的链路：

```
聊天消息 → AI(或提示词/规则) 判断语气 → 取该角色的「情绪槽参考音」→ GPT-SoVITS 合成 → 消息里出现语音 + 立绘
```

关键概念（**这四个决定效果好坏**）：

| 概念 | 说明 |
|---|---|
| **基础参考音** | 角色的"本音"，决定音色。在 `engine\fvtt_chars\<角色>\character.yaml` 的 `refer_audio_path` |
| **情绪槽（语气槽）** | 每个角色可有多套"情绪参考音"。七海千秋自带 21 个槽（平静/生气/害羞/难过…） |
| **情绪占比** | **0（默认）= 自动**：基础音作主参考 + 情绪音作**附加参考叠加**（音色不变，只加情绪味）。拉到 100% 会用情绪音**取代**基础音（音色会变，不建议） |
| **朗读提示词** | 每个角色、每位玩家独立的一句语气描述，如"用愤怒、压着火气的语气说话"。同时影响 AI 判语气、润色、立绘选择，以及语速/停顿 |

**立绘与语气是同一条线**：AI/提示词选中某个情绪槽 → 声音用该槽参考音、立绘用该槽自带的图。
所以"立绘和语气不同步"通常是没选到槽，先看 `语音设置 → 🩺 立绘诊断`。

## 二、安装

### 1) 模块（很小）
放到 Foundry 数据目录：
```
<FoundryData>\modules\gpt-sovits-tts\
```
或用 Foundry「安装模块 → 清单 URL」填：
`https://raw.githubusercontent.com/fateafate/gpt-sovits-tts/main/module.json`

### 2) 引擎（约 16 GB，需单独部署）
引擎（Python + 模型 + 角色包）**不进仓库**，需单独获取/打包：
```
<FoundryData>\modules\gpt-sovits-tts\engine\
├── runtime\           自带 Python + ffmpeg（必须）
├── GPT_SoVITS\        预训练模型与配置（必须）
├── fvtt_chars\<角色>\ 角色模型 + 参考音 + 立绘（按需，每个约 300 MB）
├── 启动引擎.bat / 启动引擎(无窗口).vbs / 停止引擎.bat
├── watchdog.vbs / 安装看门狗自启.bat / 卸载看门狗自启.bat
└── 打包引擎给别人.bat
```

### 3) 让引擎自动起来（推荐，二选一，都不弹窗）
- **跟随 Foundry 自动启动（最省心）**：双击一次 `engine\安装看门狗自启.bat`。
  之后每次登录 Windows，看门狗在后台静默运行；**只要 Foundry（30000）在跑而引擎（9881）没起，就自动用隐藏窗口拉起引擎**。
  日志：`engine\watchdog.log`、`engine\engine.log`。
- **开机就启动引擎**：双击 `engine\安装开机自启.bat`。
- 临时启动：双击 `engine\启动引擎(无窗口).vbs`（已在运行会自动跳过）。

> 模块跑在**浏览器**里，无法直接启动本地程序（浏览器安全限制）—— 所以"自动启动"由上面的无窗口看门狗实现。

### 4) 打开 Foundry → 语音设置
- 本机装了引擎：服务端地址保持默认 `http://127.0.0.1:9881`
- 状态灯变绿、或点 🏁 最终测试看到"引擎连通 ✓"即可用

## 三、快速开始

1. 语音设置 → 选角色（如 七海千秋）→ 填 **朗读提示词**（例：`害羞羞涩的语气`）
2. 发送面板（工具条 💬）→ 直接发一句
3. 期望：**语音带该语气 + 立绘是对应情绪那张**

### 四项调配：默认 0 = 全自动（交给 AI）

| 滑块 | 0 的含义 | 什么时候手动调 |
|---|---|---|
| 朗读音量 | 自动（引擎默认响度，不额外衰减） | 想安静一点 / 更响 |
| 语速 | 自动（交给朗读提示词与 AI） | 想固定语速（0.5~2.0） |
| 情绪占比 | **自动 = 基础音 + 情绪音叠加** | 想让情绪更浓（60~70 仍保音色）；**100 会取代基础音** |
| 情感参数调制 | 自动（按 AI 判定的情绪决定语速快慢） | 想减弱 / 加强情绪对语速的影响 |

### 提示词强度（每个角色独立）
- **0%**：不改变语速/停顿（但**仍会**按提示词换语气与立绘）
- **50%+**：提示词里的语速/停顿关键词开始生效
- 发送面板里的"强度"是独立一行滑块，可随时拖

## 四、AI 接入（可选，但推荐）

语音设置 → AI 接入：填 `base`（如 `https://api.deepseek.com/v1`）、密钥、模型 → 保存 → ⚡ 自动检测模型。
有 AI 时：判语气、润色台词（保持原意）、选语气槽；没 AI 时用"朗读提示词 + 文本规则"降级，**只是没有润色**。

### Token 消耗（1.6.117 起已瘦身）
- 每条消息 **1 次** AI 调用（以前 2~3 次）；同一句 30 分钟内复用判定结果
- 请求里不再发立绘表（立绘由情绪槽决定）、角色设定只发 200 字、上下文最多 2 行
- **零 token 模式**：朗读提示词已能确定语气 + 关闭"AI 润色" → **完全不调 AI**
- 查看消耗：控制台 `AI token(assess) ≈ 输入 … · 输出 …`；或 🩺 立绘诊断 / 引擎 `GET /llm/stats`

## 五、多人 / 多台电脑

| 场景 | 怎么做 |
|---|---|
| GM 电脑有显卡 | 默认：GM 本机合成，所有人听同一段 |
| 玩家用自己的电脑合成 | 语音设置 → 👥 语音生成者分配，指定某账号由哪台电脑合成 |
| 玩家没有引擎（iPad/手机） | 默认走 socket 委托给"语音生成者"，无需安装任何东西 |
| 指定机器离线 | 自动回退到默认引擎机，不会断声 |

详见 `docs/分发与多人部署指南.md`。

## 六、最终测试（发布 / 排障都用它）

语音设置 → 底部 **🏁 最终测试**（约 3~6 分钟），报告写到 `engine\final_test_report.md`：

1. **一·0 改动自检**（纯逻辑，不联网）
2. **环境与配置**（引擎 / LLM / 版本 / 立绘模式 / 调配值）
3. **AI/Key 专项**（key 有效性、模型可用性、token 统计）
4. **语气提示实测**（同句"无提示词 vs 有提示词"对照）
5. **多场景实测（6 条真实发送）**：害羞 / 愤怒 / 温柔 / 无提示词 / 手动语气槽 / AI 直出 ——
   每条都断言：语气语义、参考音送达、占比>0、**立绘=该情绪槽的图**、语速合法、合成成功
6. **立绘实物检查**（真 fetch 图片 + 页面是否插图且解码成功 + 头部头像）
7. **语气是否真的送到引擎**（打印送给引擎的情绪/参考音/占比/语速）
8. **玩家端代理合成**、**朗读白名单**、**预加载按钮**、**AI 去重**
9. **引擎自动启动（看门狗）**状态
10. **短情绪参考音兜底**、**参考音被拒时的自动降级**
11. **五、需求对照**：逐条 ✓/✗（不通过会写清是哪一条）

> 测试产生的聊天消息会在结束时自动删除，不污染记录。

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 消息只有语音没立绘 | 看 🩺 立绘诊断；若提示"未朗读"，是合成没写回（先看引擎是否在线） |
| 语气没变化 | ①情绪占比被拉到 0 但引擎版本过旧（占比字段需引擎 ≥1.6.114）②该角色没有对应情绪槽（🩺 诊断里有槽列表） |
| 音质突然变差 / 不像本人 | 情绪占比被拉到 100%（会用情绪音取代基础音）→ 调回 0（自动） |
| 引擎连不上（9881） | 双击 `engine\启动引擎(无窗口).vbs`；或装看门狗自启 |
| 引擎刚启动第一次合成很慢 | 首次要加载模型（16~136 秒），之后正常 |
| 中文被读成日语 / 英语 | 语音设置 → 朗读语言：`auto` 表示按文本自动识别 |
| 想更省 token | 关闭"AI 润色" → 提示词能定语气时完全不调 AI |
