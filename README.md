# GPT-SoVITS 语音朗读 + 听写 (FVTT TTS Voice)

Foundry VTT 模块：把 GPT-SoVITS 的角色语音带进跑团——**打字自动朗读、多人同声、角色语气、多语言翻译、本地听写**。

> **致谢声明**：本模块**借鉴了「不二咲爱笑」大佬制作的 [Shinsekai](https://github.com/TinoTinoBoo/Shinsekai)**（GPT-SoVITS 角色语音参考方案），在此**由衷感激不二咲爱笑大佬**。制作人：**跑团恶魔**，QQ 群：**775375241**。**欢迎任何人提意见或帮忙一起制作**，任何反馈（Bug、功能建议、PR）都非常欢迎！

## 功能一览

### 朗读
- **打字自动朗读**：发送即读 / 打字停顿即读（不发也能听）/ 两者 / 仅手动（可配置）
- **同一段音频全员同声**：发言者合成 → socket 广播 → 所有玩家播放**完全相同的音频**（同一个声音），任何人重听、任何人在场，音色永远一致
- **朗读原文原则**：永远朗读你发的原文，AI 只负责选语气，**绝不改写台词**
- **预加载**：发送前先合成，点发送的瞬间零等待播出
- **重听按钮**：任意历史消息可重播同一段音频（缓存复用，不重复合成）

### 角色与语气
- **多角色**：一人一音色，聊天框随角色切换，角色模型自动切换（带**互斥锁**：切换中不合成、合成中不切换，杜绝串角色）
- **语气槽**：每个角色可从 yaml 配置多个语气（每槽一段参考音频），手动选择或 **AI 按台词+角色人设自动判断**（LLM）
- **朗读风格提示词**：音频栏可输入「更严肃认真、中间不要中断」这类自然语言 → 自动翻译成语速/停顿/切分等合成参数（**每用户独立记忆**，GM/玩家互不共享）
- **情感参数调制**：按语气标签自动推断语速（愤怒快、困倦慢、悲伤缓…）
- **头部增益补偿**：修复合成语音开头偏弱（裁剪情绪样本开头静音 + 头部能量微抬升）

### 语言与翻译
- **自动语言**：跟随角色母语朗读（角色 yaml 配 `prompt_lang`），文本语言不一致时自动翻译（中夹英 → 整段翻成角色母语）
- **中英日支持**：系统语音兜底、数字本地化（中文数字读法/日文数字读法）
- **别名音译**：服务端按角色 yaml 的 `pronunciation_map` 替换专名（阿尔托莉雅·潘德拉贡 → アルトリア・ペンドラゴン）

### 硬件自适应
- 自动探测 GPU（cuda/fp16）或 CPU，显存不足自动回落 CPU 推理
- 服务端启动脚本带自动重启（最多 5 次）、端口占用检测、UTF-8 日志

### 其他
- **听写**：麦克风语音转文字直发聊天（浏览器 Web Speech / 服务端 /asr）
- **角色构建器**：导入/复制/删除角色、语气槽绑定音频并自动转写台词、语速/音量/情绪占比调校
- **广播诊断**：服务端记录每次合成与播放的实际内容（排查「播放固定同一段」类问题）
- 中英双语界面

## 安装

### 1. 模块本体（Foundry 侧）
把 `gpt-sovits-tts` 目录放进 Foundry 的 `Data/modules/`，然后在世界设置里启用模块。兼容 Foundry v11–v13（验证于 v13）。

### 2. TTS 服务（引擎侧）
模块需要两个本地服务（**引擎权重约 15GB，不随本仓库发布**，需自行准备）：

| 服务 | 端口 | 说明 |
|---|---|---|
| GPT-SoVITS api_v2 | 9880 | 音色合成引擎（模型权重、角色包） |
| 桥接服务 `server/fvtt_api.py` | 9881 | 模块实际调用：角色切换互斥、情绪融合、风格参数、LLM 语气判断、音频后处理 |

启动：`server/start-tts-server.ps1`（或 `.bat`）。服务启动后需 **1–2 分钟加载模型**，期间客户端显示「服务未连接（可能正在启动）」。

> 引擎（GPT-SoVITS 权重与运行环境）可参考 Shinsekai 的部署方式准备音色角色包；桥接服务对引擎 api_v2 的调用方式与 Shinsekai 保持一致。

### 3. 角色包
参考 `examples/` 下的角色 yaml 格式，放入服务端 `fvtt_chars/<角色名>/`（含权重与参考音频）。也可在模块的语音设置面板里直接导入/新建角色。

### 4.（可选）AI 语气判断
在语音设置里填 OpenAI 兼容 API（地址/密钥/模型），LLM 会按**台词 + 角色人设**自动挑语气槽；不填则走手动语气 + 兜底关键词推断，功能照常。

## 多人使用

- 全员听到同一段音频：**GM 那台电脑运行 TTS 服务**，GM 以 `0.0.0.0` 启动，玩家在语音设置把服务地址填成 GM 的局域网 IP（如 `http://192.168.1.5:9881`），并确认防火墙放行
- 语音档案（当前角色/语气/语速/风格提示词）**按用户隔离**，GM 与玩家互不串设置，各浏览器的悬浮窗/面板各自独立
- 广播用二进制 ArrayBuffer 传输（省体积与编码耗时），兜底超时 15s 后本地重读

## 配置项（设置面板）

- 触发方式（send/typing/both/manual）
- 朗读自己/别人的消息、朗读来源（全部/仅 GM/仅玩家）
- 跳过 OOC / 悄悄话 / 掷骰 / 富文本卡片
- 最短/最长朗读长度、朗读输出语种与翻译目标
- 语速 / 音量 / 情绪占比 / 情感参数调制 / 朗读风格提示词
- LLM API（判断语气用的 OpenAI 兼容端点）
- 服务地址（本机或 GM 局域网）
- 播放模式（排队/打断）、打字停顿毫秒

## 命令（聊天里输入）

```
/ttssay 文本        朗读文本（不发送消息）
/ttsstop            停止朗读
/ttstest            试听
/ttsrec             开/关听写
/ttshelp            命令帮助
```

## 宏 API（宏编辑器里用）

```js
game.gptSoVitsTTS.speak("火焰在森林深处低语……");        // 任意文本按当前设置朗读
game.gptSoVitsTTS.speak("こんにちは", { lang: "ja" });  // 指定语言
game.gptSoVitsTTS.stop();                               // 停止
game.gptSoVitsTTS.status();                             // {ok, data} 服务状态
game.gptSoVitsTTS.dictate();                            // 切换听写
game.gptSoVitsTTS.openVoiceManager();                   // 打开语音设置面板
game.gptSoVitsTTS.setEnabled(false);                    // 开关
```

宏示例文件见 `macros/`。

## 常见问题

- **语音失败提示服务未连接**：服务启动需 1–2 分钟加载模型；或玩家没指向 GM 的局域网地址。
- **切换角色后声音不变**：角色模型切换有互斥锁，切换需等待正在合成的请求完成（≤30s）。
- **开头声音弱**：已内置头部增益补偿；仍弱可调 `_boost_head` 参数。
- **其他玩家听不到**：确认对方硬刷新（Ctrl+Shift+R）且服务地址正确；服务端 `tts-requests.log` 有完整播放诊断记录。
- **控制台 renderChatMessage 警告**：Foundry v13 自身的废弃警告，与本模块无关，可忽略。

## 服务端接口速览（`server/fvtt_api.py` 桥接服务）

| 接口 | 说明 |
|---|---|
| `GET /status` | 服务状态、设备、当前角色 |
| `GET /characters` | 角色列表（含语气槽、人设 setting） |
| `POST /characters/switch` | 切换激活角色（互斥锁：等合成完毕再切，切换中拒接 tts） |
| `GET/POST /tts` | 合成音频（支持风格参数 text_split_method/fragment_interval） |
| `POST /llm/style` | 朗读风格提示词 → 合成参数（speed/切分） |
| `POST /llm/assess` | AI 语气判断 + 台词润色（含角色人设注入） |
| `POST /diag` | 播放诊断上报（落盘 tts-requests.log） |
