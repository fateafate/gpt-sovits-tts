## 三、1.6.51 详细修改内容

**① 改名："朗读风格" → "朗读提示词"**
- `languages/cn.json`：`stylePrompt` 值 "朗读风格"→"朗读提示词"，hint 更新（说明会作为 AI 判语气参考）
- 语音管理器/发送面板的输入框标签（原本就是"朗读提示词"回退文本，cn.json 覆盖后统一）
- 使用测试报告、`[语气判定]` 诊断日志中的"朗读风格→朗读提示词"

**② 无参考音频也有不同声音（学 Shinsekai 情绪驱动链的落地）**
- 之前：判出情绪后只在"有情绪槽参考音"时才换音频；没槽时引擎收不到 emotion → 声音完全一样
- 现在：**判出情绪（AI 或 规则/提示词）→ overrides.emotion 无条件传给 /tts** → 引擎内置 EMOTION_FX 表（`fvtt_api.py`）对音频做后处理：
  - joy：+2 半音、语速 1.06、+1dB
  - sad：-2.5 半音、语速 0.94、-2dB
  - angry：+1 半音、语速 1.03、+3dB
  - surprised：+4 半音、1.08、+1.5dB
  - fear：-1.5 半音、1.04、-1.5dB
  - calm：-0.5 半音、0.98、-1dB
- 效果：不配情绪槽参考音，也能听出"开心音调高一点、悲伤低沉缓慢、生气更响"的差别；配了情绪槽则优先真实参考音频融合

**③ /llm 超时不再卡**
- `aiJudgeEmotionNow` 开头检查 `__fvttTTSLlmBroken`（ready 3s 探测失败即置位）→ 直接返回，不再每次说话等 4s 超时

## 四、朗读提示词"参考更多"——已做到与可增强

**已做到（1.6.47 + 1.6.51）：**
1. 作为 **LLM 判语气的参考**（/llm 带 style 字段："判断语气时优先贴合该风格"）
2. 无 LLM 时**关键词→情绪映射**（严肃/认真/威严→calm、激动/兴奋→joy、害怕→fear…）
3. 关键词→**语速/停顿参数**（严肃→0.92 慢、激动→1.12 快、不中断→ct0 整段）
4. 情绪→引擎 **EMOTION_FX**（变调/变速/增益）——这就是"参考更多"后的实际声音差异

**可增强（待你拍板，见五）**：语速幅度可调、停顿/情感词扩展、提示词→变调强度联动、每角色独立情绪映射表。
