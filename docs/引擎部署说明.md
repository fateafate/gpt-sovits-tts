# 引擎部署说明 —— 压力在使用者机器（不在 Foundry 服务器）

> 目标：**语音合成的计算压力落在每个使用者自己的电脑上**，Foundry 服务器只负责聊天/文件转发。
> 引擎可以**后台静默运行（不弹窗口）**、**开机自动启动**，使用者平时完全不用管。

---

## 一、原理（压力为什么不在服务器）

```
┌─ 使用者的电脑 A (GM 客户端) ──────────────┐
│  Foundry 客户端(浏览器)                    │
│    └─ http://127.0.0.1:9881 → 本机引擎 ✅  │  ← 合成在这里跑(GPU/CPU)
├─ 使用者的电脑 B (玩家 PC) ────────────────┤
│  Foundry 客户端(浏览器)                    │
│    └─ http://127.0.0.1:9881 → 本机引擎 ✅  │  ← 合成在这里跑
└───────────────────────────────────────────┘
        Foundry 服务器：只存聊天记录 + 音频文件(静态), 不做合成
        无引擎的机器(iPad/手机)：走 socket 委托给"语音生成者"代合成
```

- **每台想分担合成的电脑各跑一份引擎**（同一个模块目录，或各自一份副本）
- 模块设置 → **服务端地址**：填**本机** `http://127.0.0.1:9881`（默认即此）
- 谁给谁生成语音：语音设置 → 👥 **语音生成者分配**（把每个玩家的语音指定到某台有引擎的电脑）
- 没有任何引擎的机器（iPad 等）：自动走 socket 把合成请求转给被分配的生成者，音频从 Foundry 服务器拉取播放

---

## 二、每台使用者机器的安装步骤（一次即可）

1. 打开模块目录的 `engine\`（本机已有引擎与角色模型即可，无需重复下载）
2. 双击 **`安装开机自启.bat`** → 以后每次开机自动在后台启动引擎（**不弹窗口**）
3. 双击 **`启动引擎(无窗口).vbs`** → 立即静默启动一次（已在运行会自动跳过，不会重复启动）
4. 打开 Foundry → 语音设置 → AI 接入/服务端地址确认为 `http://127.0.0.1:9881`
5. 点 **🧪 使用测试** 确认"引擎连通 ✓"

> 只想临时用：直接双击 `启动引擎.bat`（**带窗口**，能看到日志，关窗口=停止）。
> 想要无窗口常驻：用 `启动引擎(无窗口).vbs`（日志写到 `engine\engine.log`）。

## 三、常用脚本一览（都在 `engine\` 目录）

| 文件 | 作用 |
|---|---|
| `启动引擎.bat` | **带窗口**启动（看日志方便，关窗口即停止） |
| `启动引擎(无窗口).vbs` | **静默**启动（不弹窗口，日志写 `engine.log`；已在运行则跳过） |
| `停止引擎.bat` | 停止引擎（结束所有 fvtt_api 进程） |
| `安装开机自启.bat` | 安装开机自启（每台机器一次） |
| `卸载开机自启.bat` | 取消开机自启 |
| `_run_hidden.bat` | 内部用（无窗口启动的实际命令），不要直接双击 |

## 四、换激活角色

编辑 `_run_hidden.bat` / `启动引擎.bat` 里的 `--char` 参数：

```
--char "%~dp0fvtt_chars\七海千秋\character.yaml"
                    ↑ 改成 丛雨 等角色目录名
```
角色目录：`engine\fvtt_chars\<角色名>\character.yaml`（角色模型与立绘都在该目录内）。
多角色切换由模块自动完成（合成不同角色时引擎自动换模型），**激活角色只是默认启动项**。

## 五、排障

| 现象 | 原因 / 解决 |
|---|---|
| AI 检测提示"**语音引擎未启动(9881 连不上)**" | 引擎没跑 → 双击 `启动引擎(无窗口).vbs`；查 `engine\engine.log` |
| Foundry 控制台 `ERR_CONNECTION_REFUSED 127.0.0.1:9881` | 同上（引擎进程不在） |
| `signal timed out` | 引擎繁忙/卡住 → 1.6.62 已修"LLM 请求阻塞事件循环"；仍出现看 `engine.log` |
| 首次合成很慢（几十秒） | 正常：首次加载模型进显存；之后常驻（模块有 🚀 预加载全部角色） |
| 想确认引擎在跑 | 浏览器打开 `http://127.0.0.1:9881/status`，返回 `{"ok":true,...}` |

## 六、日志位置

- 无窗口模式：`engine\engine.log`
- 带窗口模式：直接把窗口内容复制出来
- 模块测试报告：`engine\tts-reports.log`（🧪 使用测试 / 🤖 提示词AI测试 落盘处）
