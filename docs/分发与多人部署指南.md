# 分发与多人部署指南（压力到底在谁那台电脑）

> 本文回答两个问题：**① 合成压力落在哪台机器？ ② 别人拿到这个模块后能不能直接用？**
> 所有数字与结论都基于实测（2026-10-14 核查）。

---

## 一、先说结论（实测）

| 问题 | 实测结果 |
|---|---|
| 模块仓库里有没有引擎？ | ❌ **没有**。`engine/` 被 `.gitignore` 排除，`git ls-files engine/*` = **0 个文件** |
| 引擎有多大？ | **16.3 GB / 58332 个文件**（runtime + GPT-SoVITS 预训练模型 + 角色包） |
| 单个角色包多大？ | 七海千秋 318 MB、丛雨 328 MB、五条悟 287 MB、阿尔托莉雅 317 MB |
| 别人 `git clone` / 下载 zip 后能直接用吗？ | ❌ **不能**。只能拿到脚本（scripts/ server/ styles/ languages/ docs/ ≈ 35 个文件），**没有引擎、没有模型、没有角色包** |
| 玩家需要下载引擎吗？ | ✅ **不需要**。玩家走 GM 代理合成（音频从 Foundry 服务器拉取播放）|
| 目前压力在哪台机器？ | ⚠️ **在装有引擎的那台**——而你这台正是 Foundry 服务器所在机器（实测 30000 端口 = Foundry Virtual Tabletop，引擎也在这台）|

## 二、三种拓扑 → 压力分别落在哪

### 拓扑 A：GM 客户端与 Foundry 服务器同一台电脑（你现在的情况）
```
[同一台电脑]  Foundry 服务器(30000) + GM 浏览器 + TTS 引擎(9881, 吃 GPU)
                                    ↑ 压力集中在这台
[iPad/手机玩家] 无引擎 → socket 委托给"语音生成者"(默认 GM) → 压力仍回到这台
```
**压力 = 这台机器的 CPU/GPU**。玩家多、句子多时，这台机器同时要跑 Foundry 服务器 + 引擎推理。

### 拓扑 B：GM 客户端在另一台电脑（连远程 Foundry 服务器）
```
[服务器]        只跑 Foundry(30000)，不跑引擎           ← 压力小
[GM 电脑]       GM 浏览器 + TTS 引擎(9881)              ← 压力在 GM 自己电脑 ✅
[iPad 玩家]     委托给 GM 电脑合成
```
**这就是"压力在使用者（GM）那里"**——服务器只做转发与存音频。

### 拓扑 C：每个玩家电脑各自跑引擎（压力真正分散，推荐多人场景）
```
[玩家A 电脑]  浏览器 + 引擎(127.0.0.1:9881) → 自己合成自己的角色 ✅
[玩家B 电脑]  浏览器 + 引擎(127.0.0.1:9881) → 自己合成 ✅
[服务器]      只跑 Foundry + 存音频                      ← 几乎零压力
[iPad 玩家]   没引擎 → 委托给"语音生成者"(可指定某台玩家电脑)
```

**机制上完全支持**（已核查代码）：
- 模块设置 **`服务端地址(serverUrl)` 是 client 作用域** → **每台电脑各自填自己的地址**，互不影响
- 客户端启动时探测该地址的 `/status`：**通则直连本机引擎合成**（`__fvttTTSCanDirect = true`），不通才转 GM 代理
- 所以只要"某台电脑装了引擎 + 填 `http://127.0.0.1:9881`"，它就用自己的 GPU 干活

## 二·B、零安装（推荐，也是默认行为）

**使用者不需要下载任何文件**——只要浏览器打开 Foundry 网址就能用：
- 引擎跑在**有引擎的那台机器**（通常就是 Foundry 服务器，`-a 0.0.0.0` 监听 9881）
- 客户端的"服务端地址"**默认自动指向当前 Foundry 主机**：`http://<你访问的网址>:9881`
- HTTPS 页面无法直连 http 端口时，自动走 **socket 代理**（Foundry 服务器转发到本机 9881）→ 玩家照样能用
- 玩家发出的合成请求由"引擎可达的客户端"执行，音频写回消息 flags，全员从 Foundry 服务器拉取播放

### 压力按配置指定给哪台电脑（👥 语音生成者分配）
- 位置：语音设置 → 👥 **语音生成者分配**（GM 专用；存于世界设置 `voiceRunnerMap`）
- 语义：每行 `说话者账号 = 生成者账号`——**谁的语音由谁的电脑生成**；留空 = **默认引擎机**（服务器/GM 那台）
- **1.6.75 起已真正接到合成路由上**：被指定的电脑在线时，只有它执行合成（其它机器不再重复劳动）；被指定电脑**离线时自动由默认引擎机兜底**，不会断声
- 前提：**被指定的电脑自己必须装着引擎并在运行**（否则它无法合成）；没有引擎的玩家（iPad/手机）只能被"分配给别人"，不能作为生成者
- 报告可见性：🏁 最终测试的"合成方式"行会显示 `最近一次由「XXX」的电脑合成(按语音生成者分配)`

> 结论：**要"零安装"→ 让服务器（或某台常开机器）跑引擎，谁都别装**；
> **要"压力分散"→ 让每台玩家电脑各自装引擎并在分配器里指定它**。两者都由配置决定，模块已支持。

## 三、怎么把压力搬到使用者电脑（操作步骤）

### 每台要自己合成的电脑（GM 电脑 / 玩家 PC）
1. **拿到引擎包**（16.3 GB，找你要，或用下面的打包脚本生成）
2. 放到 Foundry 数据目录的模块里：`<FoundryData>\modules\gpt-sovits-tts\engine\`
   （与模块脚本同目录；角色包在 `engine\fvtt_chars\<角色名>\`）
3. **让它自动起来（推荐，二选一）**
   - **跟随 Foundry 自动启动（1.6.107 新增，最省心）**：双击一次 `engine\安装看门狗自启.bat` → 之后每次登录 Windows，看门狗在后台静默运行；**只要 Foundry（30000）起来了而引擎（9881）没起，就自动用隐藏窗口拉起引擎**，不弹任何窗口、不用点任何东西。日志：`engine\watchdog.log`、`engine\engine.log`。卸载：`engine\卸载看门狗自启.bat`
   - **开机就启动**：双击 `engine\安装开机自启.bat`（引擎先于 Foundry 就绪，同样无窗口）
   - 临时应急：双击 `engine\启动引擎(无窗口).vbs`（已在运行会自动跳过）
4. 打开 Foundry → 语音设置 → **服务端地址填 `http://127.0.0.1:9881`**（client 作用域，只影响本机）
5. 语音设置 → 看状态灯是否变绿 / 或双击 🏁 最终测试看"引擎连通 ✓"
   - 引擎没开时，Foundry 里会**弹一次**明确提示（含上面三种启动方式），不会再在控制台反复刷 `直连TTS失败(重试3次仍败)`

> ⚠ 模块本身跑在**浏览器**里，无法直接启动本地程序（浏览器安全限制）。所以"跟随 Foundry 自动启动"是靠上面的**无窗口看门狗**实现的，而不是模块自己去 exec。

### 没有引擎的机器（iPad / 手机 / 低配电脑）
- 什么都不用装：默认走 socket 把合成请求委托给"语音生成者"
- 用 **语音设置 → 👥 语音生成者分配** 指定"谁给谁生成"（例如把某玩家的语音指定到那台有显卡的电脑）

### 硬件门槛（诚实提醒）
| 环境 | 体验 |
|---|---|
| 有 NVIDIA 显卡（6GB+ 显存）| 正常（引擎默认 CUDA，分批并行推理）|
| 只有 CPU | 能跑但**慢很多**（每句可能数秒~十几秒），适合偶尔用 |
| iPad / 手机 | **不能跑引擎**（Windows 专用），只能委托 |

## 四、把引擎分发给别人（打包）

双击 `engine\打包引擎给别人.bat` → 会在桌面生成 `gpt-sovits-引擎包\`（**只复制必要内容**，排除缓存/临时/日志）：
```
gpt-sovits-引擎包\
├── runtime\                 引擎自带 Python + ffmpeg（必须）
├── GPT_SoVITS\              预训练模型与配置（必须，含 pretrained_models）
├── fvtt_chars\<角色名>\      角色模型 + 参考音 + 立绘（按需，每个 ~300MB）
├── 启动引擎.bat / 启动引擎(无窗口).vbs / 停止引擎.bat / 安装开机自启.bat ...
├── watchdog.vbs / 安装看门狗自启.bat / 卸载看门狗自启.bat   ← 1.6.107: 随 Foundry 自动静默启动
└── （不含 .tmp_imports / __pycache__ / logs / audio_export / *.log / watchdog.lock）
```
把该目录复制给对方（U 盘/网盘），对方放到自己的 `modules\gpt-sovits-tts\engine\` 即可。

> 只想要部分角色？打包时把不需要的 `fvtt_chars\<角色名>` 删掉即可（每个省 ~300MB）。

## 五、别人拿到模块后的最小可用路径

1. 装模块（git / zip，~35 个脚本文件）
2. **必须另外拿到引擎包**（否则所有 TTS 功能不可用——界面会提示"语音引擎未启动"）
3. 按第三节步骤启动引擎 + 填本机地址
4. 角色包按需添加：把 `角色名\` 目录放进 `engine\fvtt_chars\`，在语音设置里刷新即可看到

**没有引擎时的表现**（不会崩，只是没声音）：
- 界面/日志提示"语音引擎未启动(9881 连不上)：先双击 engine\启动引擎.bat"
- AI 检测、合成、最终测试都会明确报"引擎未启动"，不会静默失败

## 六、常见误解澄清

| 误解 | 事实 |
|---|---|
| "其他人下载模块就能用" | ❌ 模块 ≠ 引擎。引擎 16.3GB 需单独分发（版权/体积原因不入库）|
| "引擎跑在玩家电脑上" | 需要**每台电脑各自装引擎并填本机地址**才会这样；默认玩家是委托给 GM |
| "iPad 也能自己合成" | ❌ Windows 引擎，iPad 只能委托 |
| "服务器压力一定大" | 若 GM 客户端不与服务器同机、且玩家各自装引擎 → 服务器几乎零压力（只存音频）|
